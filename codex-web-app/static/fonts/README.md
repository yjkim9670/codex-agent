# Included web fonts

These webfonts are served locally. The browser requests each added font only when it is selected in Workbench settings.

## Wanted Sans

- Source: https://github.com/wanteddev/wanted-sans/releases/tag/v1.0.3
- Included: `WantedSansVariable.woff2` (variable weight)
- License: `wanted-sans/OFL.txt`

## LINE Seed Sans KR

- Official source and license notice: https://seed.line.me/index_kr.html
- Official webfont archive: https://seed.line.me/src/images/fonts/LINE_Seed_Sans_KR.zip
- Included weights: Thin, Regular, Bold
- License: `line-seed-kr/OFL.txt` (SIL Open Font License 1.1)

## Goorm Sans

- Official source and license notice: https://www.goorm.io/resources/fonts
- Official font archive: https://statics.goorm.io/company/goorm-sans-all-1.0.0.zip
- Included weights: Regular, Medium, Bold
- License: `goorm-sans/OFL.txt` (SIL Open Font License 1.1)

## Paperlogy (페이퍼로지)

- Official source: https://freesentation.blog/paperlogyfont
- Official webfont repository: https://github.com/Freesentation/paperlogy/tree/main/woff2
- Included weights: Thin through Black (100–900), original WOFF2 files
- License: `paperlogy/OFL.txt` (SIL Open Font License 1.1)

## NEXON Lv2 Gothic

- Official source and usage information: https://brand.nexon.com/ko/ci-brand-guidelines/typeface
- Official font archive: https://brand.nexon.com/resources/NEXON_Lv2_Gothic.zip
- Included weights: Light, Regular, Medium, Bold (300, 400, 500, 700)
- WOFF2 files are lossless webfont conversions of the official TTF files using FontTools; glyphs and embedded copyright notices are preserved.
- Copyright and distribution provenance: `nexon-lv2-gothic/NOTICE.md`. The official archive does not contain a separate license text; refer to the official source for usage terms.
