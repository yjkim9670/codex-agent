## 계산과 해석

- 동일 모델로만 구성된 완전한 그룹의 group_actual_percent를 한 번만 집계한다. 혼합 모델 그룹, 가중 배분값 actual_percent, 예측값, API 가격 가중치는 사용하지 않는다.
- 이벤트 ID·모델·토큰을 대조하고, 다른 로컬 실행과 겹치는 구간, 학습 제외 표시, 기간 경계, 리셋 시각 미확인·변경 구간을 제외한다.
- 계산식: 합산 차감 %p ÷ 해당 표본 토큰 × 1,000,000. 전체 모델 토큰에 표본 계수를 곱해 전체 차감으로 확정하면 안 된다.
- 미수집 CLI·클라우드·계정 활동과 지연 반영을 배제할 수 없다. 사용률의 정수 표시, 미확정 0 증가 기록 때문에 편향이 생길 수 있다.
- 기록은 standard tier지만 reasoning은 low·medium·high·xhigh가 섞여 있다. 캐시율·작업 종류·측정 날짜가 모델마다 달라 같은 작업의 효율 비교로 해석하면 안 된다.
- 5시간 Luna 2구간, 주간 Sol 5구간·6.1 Sol 3구간은 초기 관측이다. Astra·6 Luna에는 검증 가능한 독립 표본이 없다.
- 사용률 샘플이 2,160건으로 남아 있어 기존 건수 제한의 영향이 의심된다. 누락된 관측은 복원하거나 추정하지 않았다.

공식 문서는 모델·컨텍스트·추론·도구·캐시가 사용량에 영향을 주며, 크레딧 가격만으로 구독 포함 한도 차감을 결정할 수 없다고 설명한다. API 가격이나 크레딧 단가를 5시간·주간 차감률로 직접 환산하지 않는다. [OpenAI 공식 설명](https://learn.chatgpt.com/docs/pricing)
