# Codex Workbench API 환산 가격 분석

기준일: 2026-08-28  
가격 출처: https://developers.openai.com/api/docs/pricing

## 결론

Workbench의 사용량은 ChatGPT/Codex 구독 한도나 크레딧 청구액이 아니라, 기록된 토큰을 같은 모델의 OpenAI API Standard 가격으로 환산한 값이다. 따라서 화면의 `API estimate`는 실제 청구서가 아닌 비교 가능한 기준 비용이다.

월간 추정 비용은 다음 식으로 계산한다.

`(입력 토큰 - 캐시 입력 토큰) × 입력 단가 + 캐시 입력 토큰 × 캐시 단가 + 출력 토큰 × 출력 단가`

모든 단가는 1M 토큰당 USD이며, 추론 토큰은 API usage의 output 토큰에 이미 포함되므로 별도로 더하지 않는다.

## 비용을 좌우하는 요소

출력 토큰은 대체로 입력보다 훨씬 비싸므로, 모델별 총 토큰보다 입력·캐시 입력·출력 분해를 함께 보는 것이 중요하다. 캐시 입력은 일반 입력 대비 약 90% 낮은 단가여서 장기 세션에서 캐시 비율이 높으면 환산 비용이 크게 낮아진다.

Workbench는 가격표에 정확히 대응하는 모델만 합계에 넣고, 과거/내부 별칭처럼 공개 가격표에 매핑할 수 없는 기록은 `unclassified_legacy`로 분리한다. 이는 비용을 임의로 추정해 과대·과소 표시하지 않기 위한 처리다.

## 실제 API 청구와 차이가 날 수 있는 경우

- 272K 이상 장문 컨텍스트는 일부 GPT-5.x 모델에서 더 높은 long-context 단가가 적용된다.
- Fast 모드는 Standard와 다른 단가이며, 구독형 Codex의 Fast 사용은 API 청구가 아닌 크레딧 배수 체계다.
- 데이터 레지던시 대상 엔드포인트는 10% 가산될 수 있다.
- 웹 검색, File Search, Hosted Shell/Code Interpreter 등 도구 호출 비용은 토큰 단가와 별도로 발생한다.
- Batch/Flex는 Standard와 다른 할인 단가다.

따라서 월간 비교에는 Usage History의 30일 모델별 `API estimate`를 사용하되, API 회계·예산 보고에는 OpenAI Usage dashboard의 실제 비용을 최종 기준으로 사용한다.
